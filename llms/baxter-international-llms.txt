# Baxter International

> Baxter International is a global medical products company (NYSE: BAX) making infusion
> systems and pumps, IV fluids and injectable medicines, patient monitoring and diagnostic
> devices, hospital beds and patient mobility, surgical equipment, and care-communications
> systems. Its connected-care portfolio moves device data into hospital EMRs. Baxter acquired
> Hillrom in December 2021, which had acquired Welch Allyn in 2015; the Hillrom and Welch Allyn
> brands and their integration surfaces are now Baxter's.

## What an agent should know first

Baxter publishes NO public API. There is no OpenAPI, AsyncAPI, GraphQL schema, WSDL, MCP server
or A2A agent card on any Baxter, Hillrom or Welch Allyn host. Integration surfaces exist and are
real, but they are obtained by contacting Baxter as an OEM or EMR partner and signing a licence -
there is no self-serve signup, no API key, no sandbox and no published base URL. An agent cannot
call Baxter. A human integrator can license an SDK from Baxter and then call devices locally.

## Integration surfaces (all OEM/partner licensed)

- [EMR Connectivity](https://support.baxter.com/en/resources/it-resources/emr-connectivity/):
  the single developer-facing page. States verbatim: "For information on Software Development
  Kits (SDK), CARDIOPERFECT API as an Original Equipment Manufacturer (OEM), interface
  development partnerships, or licensing and marketing, please contact us." Baxter reports well
  over 600 device interfaces and integrations with more than 150 EMR companies.
- [Welch Allyn Connectivity SDK - Development Best Practices](https://www.hillrom.com/content/dam/hillrom-aem/us/en/sap-documents/LIT/80019/80019598LITPDF.pdf):
  the most technical public document Baxter publishes. SDK 3.0.x, Windows only. Three interface
  technologies - COM API, ActiveX (WA_Vitals3ActiveX, with WA_Vitals2 kept for backward
  compatibility), and a Web Services API. Sample code in C#, ATL COM, JavaScript, VB.NET, VB6,
  MFC and Delphi. Transports are USB and Bluetooth to the device; it is a local integration, not
  a network API. Devices: Spot 4400, Connex Spot Monitor, Connex Vital Signs Monitor, Connex
  Integrated Wall System, Connex ProBP 3400, Spot Vital Signs LXi.
- [Current EMR Partners](https://support.baxter.com/en/resources/it-resources/emr-partners/)
- [Software Downloads](https://support.baxter.com/en/resources/it-resources/software-downloads/):
  device drivers and software updates; some releases are obtainable only by phoning support.
- [Contact / access request](https://support.baxter.com/en/contact-us/): the gate.
